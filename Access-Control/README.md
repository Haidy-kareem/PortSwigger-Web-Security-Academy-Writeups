# Access Control

This folder contains write-ups for Access Control labs from PortSwigger 
Web Security Academy. The included write-ups cover the labs that I found 
most useful for understanding access control vulnerabilities, privilege 
escalation techniques, and bypass methods.

## Covered Concepts
- URL-based access control bypass
- Method-based access control bypass
- Insecure Direct Object References (IDOR)
- Multi-step process vulnerabilities
- Referer-based access control bypass

## Write-ups
- Lab: Referer-based access control
- Lab: Multi-step process with no access control on one step
- Lab: URL-based access control can be circumvented
- Lab: Method-based access control can be circumvented
- Lab: Insecure direct object references
