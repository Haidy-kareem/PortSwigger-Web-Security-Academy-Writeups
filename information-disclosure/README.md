# Information Disclosure

This folder contains my write-ups for Information Disclosure labs from PortSwigger Web Security Academy. The included write-ups cover all the labs in this category from how sensitive information can leak through error messages, debug pages, backup files, and version control history, to how attackers can chain that leaked information into full authentication bypasses via custom headers.

## Covered Concepts

* Verbose Error Messages
* Debug Pages & Stack Traces
* Source Code Disclosure via Backup Files
* Version Control History Leaks (.git)
* HTTP Header-Based Authentication Bypass
* Chaining Information Disclosure into Access Control Bypass
