# OS Command Injection

This folder contains my write-ups for OS Command Injection labs from PortSwigger Web Security Academy. The included write-ups cover how user input can end up being executed as system commands, and different techniques for detecting and exploiting this — even when there's no direct output returned to the response.

## Covered Concepts

* Command Injection via Shell Metacharacters
* Blind Command Injection
* Time-Based Detection (time delays)
* Out-of-Band Data Exfiltration (output redirection)
